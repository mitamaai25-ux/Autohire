# AutoHiree

AutoHiree is a professional AI-built website concept for hiring and freelancing.

## Pages
- `index.html`: Main marketing website for companies and freelancers.
- `admin.html`: Local-storage based admin portal for login, leads, and project management.

## Features
- AI hiring platform themed UI with company and talent journeys.
- Consultation request form that stores leads in `localStorage`.
- Admin login flow (local only), lead viewer, and project manager.
- Project sync: projects added in admin are shown on the main page.

## Run locally
Open `index.html` directly in your browser.
